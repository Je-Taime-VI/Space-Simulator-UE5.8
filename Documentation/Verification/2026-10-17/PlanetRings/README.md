# 四巨行星星环验证

日期：2026年10月17日。引擎：UE 5.8.2。地图：SolarSystem，正常PIE视口，1376×808。所有图片均为实际游戏截图，没有补画环或合成修复效果。

## 完成范围

保留程序化环形网格，四巨行星共用半透明`M_Rings`；土星同步更新。星环按行星的姿态、位置和远景压缩变换，物理半径按公里换算。太阳方向与照度各自计算。环带径向位置与视觉取舍见[资料说明](../../../../SourceAssets/SolarSystem/Rings/README.md)。

正式构建`Build.log`结果为Succeeded，重启后编译保存材质/地图。构建仍有既有浮点精度警告，不表示所有警告清零。`ModelValidation.json`无失败项；`TransformChecks.json`记录四颗行星的环与球体中心、姿态一致，均使用同一父材质。

## 图像采集

- 改动前：四颗巨行星各1张固定正光机位。原来只有土星有环，原始记录为`before.json`。
- 第一轮：四颗巨行星各正光、背光、近乎侧视、近环4类机位，共16张，记录为`after.json`。
- 土星密集环带增加颜色细纹后，仅复采土星4个机位，记录为`finalSaturn.json`。`Results.json`中的16张最终图使用这组土星结果，其余沿用第一轮，未把旧候选图冒充最终土星图。
- 最终材质下四个天体各采集8帧静止、16帧平移/转向、8帧返回，共128张；另留8帧返回后的稳定时间，不计入截图数。木星/海王星选背光，土星/天王星选正光。原始数据在`Saved/Diagnostics/PlanetRings_20261017/motion`，精选图归档到`Images/2026-10-17/PlanetRings`。

## 检查结果

- 所有最终机位都读到四个环组件，活动天体的尺度与半径厘米值一致。组件中心和姿态与对应球体匹配，覆盖当前活动天体和三个远景天体。
- 土星主要宽环、缝隙、内侧透光及行星投影可辨；背光下密集带与稀薄带明暗关系不同。旧等间距高对比纹理改为过滤后的多尺度细纹。
- 天王星远景主要显出最强窄环；弱环随像素覆盖降低。木星和海王星的普通正光机位非常淡，逆光时主环更明显，没有设置固定角度的显示开关。
- 抽查移动与返回帧未见整片环带消失。运动中的极细线和轮廓仍能看到像素级颗粒/锯齿，不能宣称所有速度、分辨率与抗锯齿设置下无闪烁。
- 同机位静止及返回帧的固定区域RGB峰峰值第99百分位：木星3.67、土星2.00、天王星1.33、海王星2.67（量程255）。这一区域含行星与背景，不是只含星环；该指标不评价移动视差，也不能等同于闪烁误差率。
- 检查期间`r.VolumetricRenderTarget=0`及`r.SkyAtmosphere.AerialPerspectiveLUT.FastApplyOnOpaque=0`始终保留。没有改变云材质、云采样、大气高度或曝光。

## 开销与未完成项

每个环1024段、2050顶点、2048三角形，四个环共8192三角形，无碰撞。最终材质编辑器统计726条像素指令、0次像素纹理采样；该统计不是每个像素的实际分支成本或GPU耗时。没有新增纹理，新增三个组件和半透明计算，未进行稳定前台FPS基准。

当前是视觉增强的远景环面，不是严格测量密度或人眼测光。没有木星立体晕环、土星广域E/G环、海王星局部环弧、巨行星卫星阴影、环对行星表面的投影、颗粒和穿环碰撞。全球云直接绘制配置未改变，但本轮没有完整验证从地球/金星云内看远处环的合成，也未验证水体/玻璃叠加。

NASA Eyes交互页面加载超时，结论依据公开代码只读核查、环数据与项目画面；尚未完成网页同机位外观匹配。最终结果不能描述为网页逐像素复刻。

同日晚已补充4张NASA Eyes实际截图至`Images/2026-10-17/PlanetRings/EyesReference`，完成定性对照，见开发日志第09—11条。天王星蓝红外环层次、海王星正光淡宽带可见性及土星环对星球表面的投影仍有差异；太阳方位、机位和曝光未匹配。本次没有运行资产变化，也没有新增渲染回归，原有测试结果保持其原验证范围。

## 重现与回退

- 退出PIE，在编辑器Python中调用`refine_solar_rings.main()`重建星环材质。两个总材质生成脚本也调用相同入口。
- 运行`verify_planet_rings.start()`采集机位；结束后调用`start_motion()`采集连续帧。不要重叠运行两个相机测试。
- `archive_planet_ring_checks.py`需要NumPy和Pillow，可用已配置的工作区Python运行；MCP工具虚拟环境没有这些包，不要为了归档给UE运行环境安装依赖。
- 备份为`Saved/Backups/PlanetRings_20261017`。回退需配套恢复组件源码、材质和两个生成入口后正式编译，不应回退此前云/大气配置。
