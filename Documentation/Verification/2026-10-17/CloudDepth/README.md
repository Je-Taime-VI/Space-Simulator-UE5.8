# 远距离云层深度验证

处理日期：2026年10月17日（Asia/Shanghai）。原始问题图拍摄于2026年10月16日。UE 5.8.2，SolarSystem地图。

## 定位与改动

在J2000+26.22日、地球半径之外约21024.328 km的整球机位复现左下侧成片漏云。冻结时间仍有可见性波动。

本机引擎`VolumetricRenderTarget.cpp`的追踪深度使用`PF_G16R16F`；模式3合成在`VolumetricRenderTarget.usf`中把云深度与场景距离比较，失败即丢弃。半精度值在21024 km附近的间隔为16 km，超过地球7 km云层厚度。`VolumetricCloud.usf`输出经过贡献加权的公里深度，量化可能颠倒云与地表的前后关系。

只切换`r.VolumetricRenderTarget`的同条件对照支持该机制。修正设置为0，使云直接绘制到场景颜色，绕过中间云深度合成；保留体积云本身与追踪中的场景遮挡。模式3参数保留但不参与关闭目标后的路径。没有修改引擎、云密度材质、层高、采样倍率或纹理资源。

## 连续帧证据

- `comparison.json`与`comparison-metrics.json`：两条路径共112帧，每条包含16帧静止、24帧微小平移/转向、16帧返回。
- `restart-final.json`与`restart-final-metrics.json`：重启后自动读入目标关闭配置，再按原位姿执行56帧连续采集。
- `Regression.json`：地球整球、20 km、5 km云内，金星月牙与58 km云内，共30张正常视口截图；配置、显示和材质用途检查同时执行。
- `Pose.json`保存复现位姿和天文时刻；正常视口分辨率1376×808。使用Shot保留时域渲染，没有使用HighResShot。
- 精选前后图在`Images/2026-10-17/CloudDepth`；完整原始帧位于`Saved/Diagnostics/CloudDepth_20261017`。本目录工具副本对应实际采集及分析版本。

固定统计区域为画面坐标(390,170)—(985,725)，排除HUD。初次有效对照中，32张静止/返回帧的像素亮度峰峰值超过20/255的占比，从目标开启时4.4209%降至直接路径0.00242%；第99百分位峰峰值约59.67→9.00。统计反映同位姿亮度波动，不是所有画面下云缺失率，也不能代替对真实遮挡和其他视点的检查。

第一次重启采集中，Shot短暂捕获了编辑器预览而非PIE视口（无HUD），不能与游戏帧混合统计。该批保留在Saved的`restart`目录，未用于通过结论；分析工具增加HUD存在检查，等待视口稳定后重新采集`restart-final`。前后对照与回归图像均核对视口类型。

## 性能与限制

同机位旧目标开启/直接绘制的单次云GPU事件约1.778/1.441 ms，原始记录见`ComparisonGpu.txt`。后台时钟和编辑器视图影响测量，不作为稳定FPS保证。采样倍率仍为0.25，64³密度纹理保持原样；本轮没有新增运行时资源。

全局云配置影响使用该路径的场景，厂商演示关卡未逐一复测。真实水体、玻璃及其他半透明表面的云合成需要后续单独验收；本轮没有接入这些功能。C++只调整解释注释，没有改变执行逻辑，也没有进行不必要的原生重新构建。
