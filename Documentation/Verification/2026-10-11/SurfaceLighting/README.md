# 地表受光与曝光校准验证

执行日期：2026年10月11日。项目为 BigWorld，UE 5.8.2，Win64 Development Editor；地图 `/Game/SolarSystem/Maps/SolarSystem`。

## 验证结果

- `BuildEditor.txt`：地球大气底面修正后的正式构建成功，18.58秒；随后重新启动编辑器加载新DLL。
- `MaterialAudit.json`：8个最终材质有有效编译统计；地表与海洋均为 Default Lit，Base Color有连接，自发光常数为零；基准EV100约14.966。
- `before.json`：实施前6个视图的基线，时间为J2000、输入冻结。
- `after.json`：首次受光版本6个视图；包含后来修正的地球海面暗格。月球、金星、火星地表对应最终材质与照明设置。
- `final.json`：最终正式构建9个视图，地球地面、300 km过渡、轨道与夜面，月球夜面，水星地面及太阳、土星、海王星轨道。运行断言无错误。
- `LightResponse.json`：地球同机位关闭太阳和天空光，再恢复并反向观察。8阶段曝光方式均为Manual，补偿均为约−0.04853677 EV；转向不触发图像亮度适应。
- `VerificationSummary.json`：15个修改后视图照度符合120000 lux除以日心距离AU的平方，曝光补偿符合距离预设；与基线重叠的9组视图位置/旋转差异均在0.001 cm/度以内。无大气与夜面样点天空光为零。

图像辅助统计取地球画面矩形 `(700,350)—(1150,620)`，避开HUD和天空。太阳/天空光开启、关闭、恢复后的RGB字节均值分别约69.10、0、69.04；开启与恢复的平均绝对字节差约0.36。图像只读分析，没有修改原始截图。这是色调映射后亮度比较，不是场景辐射计量。

## 范围与复核

入口为 `Tools/verify_surface_lighting.py`，在太阳系PIE中加载后调用 `start(stage)`，可传入视图列表。`LightResponseProbe` 用于同机位开关灯与转向记录，`inspect_materials_and_light()` 检查最终材质连接。夜面探针使用本地 `Saved/Diagnostics/SurfaceLighting/before.json` 的白昼位置；新环境先生成基线或将本目录对应报告复制到该位置。

验证未覆盖Shipping、全位置昼夜、地下/水下视点、完整反射/间接光照，也未实施沙石细节或海浪/折射。本次GPU抽样没有有效场景绘制事件，已排除，不能给出新增天空光的性能增减或稳定FPS结论。UE启动时既有引擎自检错误另见项目说明，不能将局部验证写成全部引擎测试通过。

检查结束后已停止PIE、恢复原编辑器视角；运行中的诊断关灯和暂停未保存。地图及内容包无未保存改动，地图时间倍率为1。备份位于 `Saved/Backups/SurfaceLighting_20261011`，不随此证据目录入库。
